# Counterfactual Network SLM

Research infrastructure for investigating evidence-grounded network fault diagnosis with small language models.

**Status:** Stage B research engineering setup. No fine-tuned diagnosis model or validated experimental results are included yet.

The scientific question is whether parameter-efficient fine-tuning can resist misleading fault reports while responding to verified changes in network telemetry.

See the Stage B pull request for the initial Python package, reproducibility utilities, tests, documentation, and CI workflow.

Do not commit model weights, private logs, credentials, or datasets without permission. Research novelty remains under investigation.
